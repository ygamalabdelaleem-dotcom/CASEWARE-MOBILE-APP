# متابعة سيزون المراجعة

تطبيق ويب (PWA) عربي لمتابعة ملفات المراجعة والفريق والمعلقات من الموبايل. **Caseware يظل مكان تنفيذ وتوثيق المراجعة**؛ التطبيق للمتابعة فقط، والتحديث يدوي أو باستيراد Excel (لا توجد مزامنة تلقائية مع Caseware).

## نسختان

| | GitHub Pages (مجاني) | نسخة الخادم |
|---|---|---|
| التشغيل | بدون خادم | Node.js + HTTPS |
| البيانات | على هذا الجهاز فقط (خذ نسخة احتياطية) | مشتركة للفريق مع مزامنة |
| الإشعارات | تظهر داخل التطبيق عند فتحه | Web Push على شاشة القفل |
| الحسابات | مستخدم واحد، والفريق أسماء فقط | دخول وصلاحيات لكل عضو |

نفس الواجهة (مجلد `docs/`) تعمل بالوضعين: على `github.io` تعمل محليًا تلقائيًا.

## النشر على GitHub Pages

1. في المستودع: **Settings ← Pages**.
2. Source: **Deploy from a branch** ← Branch: **main** ← Folder: **/docs** ← Save.
3. بعد دقيقة يعمل على: `https://ygamalabdelaleem-dotcom.github.io/CASEWARE-MOBILE-APP/`
4. على الآيفون: افتحه في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

لتجربة الوضع المحلي على جهازك: افتح أي رابط للتطبيق مع `?mode=local` (وللرجوع `?mode=server`).

## تشغيل نسخة الخادم

```bash
npm install
npm start          # http://localhost:3000
npm test           # اختبارات القواعد والمزامنة والإشعارات
```

يتطلب Node.js 22.5 أو أحدث (قاعدة SQLite مدمجة). الواجهة في `docs/`، والبيانات في مجلد `data/` (قاعدة البيانات، المرفقات، مفاتيح VAPID، النسخ الاحتياطية اليومية).

## النشر على HTTPS (مطلوب للآيفون والإشعارات)

أسهل طريقة: خادم بنطاق خاص + [Caddy](https://caddyserver.com) يصدر شهادة تلقائيًا:

```
audit.example.com {
  reverse_proxy localhost:3000
}
```

وشغّل التطبيق بـ `TRUST_PROXY=1 VAPID_SUBJECT=mailto:you@example.com npm start`.
بديل: `TLS_CERT=... TLS_KEY=...` لتشغيل HTTPS مباشرة.

| متغير | الوظيفة |
|---|---|
| `PORT` | المنفذ (3000) |
| `DATA_DIR` | مجلد البيانات |
| `TRUST_PROXY=1` | خلف بروكسي HTTPS |
| `VAPID_SUBJECT` | بريد/رابط المرسل لخدمات الإشعارات (مطلوب صالحًا لـ Apple) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | اختياري؛ وإلا تُولَّد وتُحفظ في `data/vapid.json` |

## التثبيت على الآيفون وتفعيل الإشعارات (iOS 16.4+)

1. افتح الرابط في Safari وسجّل الدخول.
2. زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. افتح التطبيق من الأيقونة ← الإشعارات ← «تفعيل الإشعارات» ← سماح.
4. اضغط «إرسال تجريبي» للتأكد، وراجع «سجل الإرسال».

## ما الذي يعمل

- **التنظيم**: شركات، ملف مستقل لكل سنة (الفريق، المسؤول، المدير، موعد التقرير، المرحلة، رابط Caseware)، أقسام وأكواد قابلة للتخصيص، قوالب، ترحيل لسنة جديدة يمسح النتائج والاعتمادات والتواريخ.
- **البنود**: مهمة / طلب مستند / ملاحظة / فرق — مع المسؤول، الأولوية، الموعد، آخر متابعة، الخطوة التالية، مرجع ورابط ورقة العمل، الاعتماديات، مرفقات (تصوير بالكاميرا) وتعليقات.
- **قواعد المراجعة** (مطبقة على الخادم والجهاز): الإقفال باعتماد مراجع مخوّل فقط ولا يعتمد أحد بندًا مسندًا إليه؛ استلام المستند أو رد العميل لا يغلق البند؛ نسبة التنفيذ منفصلة عن الاعتماد؛ تعديل النتيجة أو الأدلة (بما فيها المرفقات) بعد الاعتماد يعيد فتح البند تلقائيًا ويُسجَّل.
- **الرئيسية**: مهام اليوم، المتأخرات، طلبات العملاء، الجاهز للمراجعة، وموانع إصدار كل تقرير مع تاريخ آخر تحديث.
- **دون اتصال**: كل التعديلات والمرفقات تُحفظ على الجهاز وتُرفع عند الاتصال؛ التعارضات تظهر حقلًا بحقل للاختيار بين نسختك ونسخة الخادم.
- **الإشعارات**: جدولة على الخادم كل دقيقة (لا مؤقتات في المتصفح)؛ ملخص صباحي، قبل الاستحقاق ويومه، متابعة المتأخر وطلبات العميل، الجاهز للمراجعة، مراجعة أسبوعية؛ ترتيب بالأهمية والتأخير وقرب التقرير وتأثير البند على غيره؛ تجميع حسب الملف، منع التكرار، ساعات هدوء، أيام عمل، حد يومي، تكرار قابل للتعديل؛ إخفاء التفاصيل على شاشة القفل؛ صندوق وسجل إرسال. التصعيد للمدير معطّل إلا بتفعيله يدويًا لكل ملف. لا يراسل التطبيق العميل أبدًا؛ «رسالة النواقص» تُجهَّز للمراجعة ثم تشاركها بنفسك.
- **أخرى**: صلاحيات (4 أدوار)، سجل تعديلات، استيراد/تصدير Excel بمعاينة، نسخ احتياطي يومي وتنزيل/استعادة JSON.

## حدود معروفة

- الوصول الفوري للإشعارات غير مضمون (يعتمد على Apple/المتصفح).
- التصدير والاستيراد وإنشاء/ترحيل الملفات وسجل التعديلات تحتاج اتصالًا.
- تم الاختبار آليًا في Chromium بمحاكاة iPhone للنسختين (دون اتصال، المزامنة، التعارض، المرفقات، التصدير/الاستيراد، النسخ الاحتياطي والاستعادة، قابلية التثبيت) واختبارات وحدات للخادم. **لم يُختبر بعد على آيفون فعلي** — اتبع خطوات التثبيت أعلاه للتحقق من التثبيت والإشعارات والكاميرا.
